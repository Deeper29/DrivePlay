# DrivePlay

可视化驾驶与泊车原理练习

中文版低速汽车几何模拟网站。通过俯视车辆、前轮转角、前后轮轨迹与操作指南，帮助学习倒车入库、侧方停车和方向回正的基本原理。

> 用于理解原理，不替代教练指导或实车训练。不要将本网站中的固定位置、转角或操作时机直接套用到真实车辆上。

## 在线部署：GitHub Pages

本项目是无构建步骤的静态网站，适合直接使用 GitHub Pages 托管。

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
3. 选择 **main** 分支与 **/ (root)** 目录，点击 **Save**。
4. 等待 GitHub 完成首次部署；Pages 设置页显示的 **Visit site** 链接就是在线地址。

后续更新 `main` 后，GitHub Pages 会自动重新部署。页面资源与首页导航均采用相对路径，兼容 GitHub 项目站点的 `/DrivePlay/` 子路径。根目录的 `.nojekyll` 用于直接发布静态文件。

## 本地运行

需要 Node.js 20 或更新版本，无需安装运行依赖。

```sh
git clone https://github.com/Deeper29/DrivePlay.git
cd DrivePlay
npm start
```

浏览器打开终端显示的 `http://localhost:4173`。自定义端口：`PORT=8080 npm start`。

```sh
npm test
```

测试使用 Node.js 内置测试框架，涵盖转向几何、倒车方向、阿克曼转角、内轮差、制动换向、碰撞、停车判定、可完成的练习路线及静态站点子路径兼容性。

## 操作

先点击练习场，让键盘焦点进入模拟器。

| 按键  | 动作                                     |
| ----- | ---------------------------------------- |
| W / ↑ | 按住前进                                 |
| S / ↓ | 按住倒车；反方向输入先制动至停止，再换向 |
| A / ← | 按住逐渐向左打方向                       |
| D / → | 按住逐渐向右打方向                       |
| C     | 自动将前轮回正，不会自动摆正车身         |
| 空格  | 制动                                     |
| P     | 暂停 / 继续                              |
| R     | 重置当前练习                             |
| ?     | 操作指南                                 |

松开方向键会**保留转角**，便于观察，不模拟实车随速度和轮胎力变化的自动回正。松开前进 / 倒车会主动减速，这是面向学习的简化控制，并不代表真实自动挡车辆的怠速行为。N / D / R 仪表仅表示静止、前进与倒车状态，不是可独立选择的实际变速箱挡位。手机和触屏设备提供按住式按钮，支持转向与移动同时操作。离开窗口或切换标签页自动暂停，避免卡键。

### 练习内容

- **倒车入库**：从车头朝右的初始位置，观察右打倒车时车尾进入下方车位、车头向外摆动的过程。
- **侧方停车**：在右侧两辆车之间倒入车位，用反打方向把车头收进来，再前后调整。
- **自由探索**：打开转弯圆心，固定转角分别前进与倒车，比较四条车轮轨迹。

停车成功要求车身全部进入绿色区域、朝向误差不超过 7°、速度低于 0.08 m/s 并持续 0.7 秒。碰撞会阻止车辆进一步驶入障碍物，可反向驶离后继续调整。

## 车辆模型

`physics.js` 独立于界面，可直接测试。

- 轴距 `L = 2.70 m`，车身宽 `1.80 m`，车长 `4.46 m`，轮距 `1.55 m`。
- 参考位置为**后轴中心**，屏幕 x 向右、y 向下，航向 0 指向屏幕上方，正航向为顺时针。
- 等效前轮最大转角 ±35°，方向盘示意采用固定 15:1 转向比。这些是示例轿车参数，不对应特定车型。
- 低速运动学自行车模型：`headingRate = v × tan(steer) / L`，后轴中心按圆弧精确积分，四个实际轮迹由车体坐标转换得到。
- 前轮按阿克曼几何显示：`R = L / tan(steer)`；左、右前轮角分别为 `atan(L / (R + track/2))`、`atan(L / (R - track/2))`。因此转弯内侧前轮转角更大。
- 默认使用正常速度，上限 `1.65 m/s`（约 5.9 km/h）；打开现有的“慢速练习”开关后，上限为 `0.72 m/s`（约 2.6 km/h）。前进和倒车采用相同限速以便学习。
- 碰撞采用车身矩形的分离轴测试（SAT），每个物理子步不超过 `1/120 s`。不模拟碰撞冲击和损坏，矩形不精确覆盖后视镜或转向后轮胎突出部分。
- 预测线显示保持当前转角时约 7.65 m 的轮迹，方向使用当前或最近行驶方向，初始默认为倒车。**轮迹不是车身扫掠包络，更不是无碰撞保证。**

### 模型边界

未模拟轮胎侧偏、打滑、悬架、坡度、不同载荷、转向助力、机械回正、后视镜视野、盲区和真实踏板/变速箱逻辑。俯视画面提供了现实驾驶中无法直接获得的全局视野，不能训练真实观察能力。实际驾驶应低速操作，并由教练指导。

## 项目结构

```text
index.html              页面与操作指南
styles.css              响应式布局与视觉样式
app.js                  Canvas 绘制、输入与练习流程
physics.js              独立低速运动学和碰撞模块
server.mjs              无依赖本地静态服务器
package.json            启动与测试命令
assets/steering-wheel.png 用户提供的产品图标
.nojekyll               GitHub Pages 静态发布标记
tests/physics.test.js    运动模型回归测试
tests/scenarios.test.js  场景可完成性与帧率独立性测试
tests/site.test.js       静态资源与子路径兼容性测试
```

也可将 `index.html`、`styles.css`、`app.js`、`physics.js` 和 `assets/` 目录放到其他静态网站托管服务部署。页面不使用账户、数据库、分析埋点或本地存储。Google Fonts 是可选字体请求，无法访问时使用系统中文字体，不影响驾驶功能。
